# Онлайн-очередь к двум преподавателям

Готовый вариант для **GitHub Pages + Supabase**.

## Что работает

- две отдельные очереди;
- при добавлении вводится фамилия;
- выбор преподавателя;
- новый человек становится в конец выбранной очереди;
- кнопка **«В конец»** переносит свою запись в конец;
- кнопка **«✓ Ответил»** удаляет свою запись;
- общая очередь одинакова для всех посетителей;
- обновление каждые 3 секунды;
- статический сайт можно бесплатно разместить через GitHub Pages;
- база очереди хранится в Supabase.

## 1. Создайте Supabase

1. Откройте https://supabase.com/
2. Создайте аккаунт и новый Project.
3. Откройте **SQL Editor**.
4. Создайте новый SQL-запрос.
5. Скопируйте туда содержимое файла `supabase.sql`.
6. Нажмите **Run**.

## 2. Получите настройки Supabase

В панели проекта найдите:

- **Project URL**
- **Publishable key** (или legacy `anon` key)

Обычно они находятся в **Project Settings -> API** или в окне **Connect**.

НЕ используйте `service_role` / secret key.

## 3. Заполните config.js

Откройте `config.js`:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://ВАШ-ПРОЕКТ.supabase.co",
  SUPABASE_ANON_KEY: "ВАШ_PUBLIC_KEY"
};
```

Публичный Publishable/anon key можно хранить в GitHub Pages: права доступа ограничены SQL-функциями в `supabase.sql`.
Secret/service_role key в браузер добавлять нельзя.

## 4. Загрузите на GitHub

Создайте новый репозиторий и загрузите в корень:

- `index.html`
- `style.css`
- `app.js`
- `config.js`
- `supabase.sql`
- `README.md`

## 5. Включите GitHub Pages

В репозитории:

**Settings -> Pages -> Build and deployment**

Выберите:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Сохраните.

Через некоторое время GitHub покажет адрес вида:

`https://USERNAME.github.io/REPOSITORY/`

## Важная особенность

Управление своей записью привязано к браузеру через локальный случайный токен.
Если человек очистит данные браузера или откроет сайт с другого устройства,
он всё ещё увидит себя в общей очереди, но кнопки управления этой записью у него не появятся.

Если нужна авторизация студентов между устройствами, следующий шаг — добавить Supabase Auth.

## Изменение имён преподавателей

В `index.html` замените все надписи:

- `Преподаватель 1`
- `Преподаватель 2`

на реальные ФИО.
